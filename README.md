# ZIP Password Cracker

패스워드가 걸린 ZIP 파일을 **사전공격 + 무차별 대입(brute force)**으로 크랙하는 파이썬 도구.
사전공격과 브루트포스를 여러 프로세스로 동시에 실행하며, 하나가 비밀번호를 찾으면 나머지는 즉시 중단한다.

> ⚠️ **이 도구는 본인 소유이거나 명시적으로 허가받은 파일에만 사용해야 합니다.**
> 타인의 파일을 무단으로 크랙하는 행위는 정보통신망법 등 관련 법률 위반이며, 그로 인한 책임은 사용자 본인에게 있습니다. 이 프로젝트는 보안 학습 및 인가된 테스트 목적으로만 제공됩니다.

---

## 주요 기능

- **사전공격(Dictionary attack)** — rockyou 등 워드리스트의 비밀번호를 한 줄씩 대입
- **무차별 대입(Brute force)** — 지정 길이의 모든 문자 조합 시도 (기본 1~4자)
- **병렬 처리** — `multiprocessing`으로 CPU 코어를 나눠 써 여러 공격을 동시에 실행
- **조기 중단** — 한 프로세스가 비밀번호를 찾으면 공유 신호로 전체 즉시 종료
- **AES / ZipCrypto 모두 지원** — `pyzipper` 사용 (구형 ZipCrypto + 최신 AES-256 암호화 zip)

## 사용법

```bash
python zip_password.py
```

```
입력>> test.zip
```

- 크랙할 ZIP 파일 경로를 입력하면 공격이 시작됩니다.
- 비밀번호를 찾으면 화면에 출력됩니다.
- `exit` 입력 시 종료됩니다.

## 동작 원리

1. **기준 검증 방식** — ZIP 내부 파일 하나만 읽어(`read`) 비밀번호를 검증한다.
   전체를 디스크에 풀지(`extractall`) 않으므로 빠르고 부작용이 없다.
2. **왜 multiprocessing인가** — ZIP 암호 검증은 CPU 바운드 작업이다.
   파이썬 스레드는 GIL 때문에 CPU 병렬성을 얻지 못하므로, 코어를 실제로 나눠 쓰는
   `multiprocessing`(프로세스 기반)이 올바른 선택이다.
3. **작업 분배** — 사전 파일별 워커 + 브루트포스 길이 구간별 워커를 프로세스 풀에 던지고,
   `multiprocessing.Manager().Event()`로 "찾음" 신호를 공유해 조기 종료한다.

## 한계

- 브루트포스는 현실적으로 짧은 길이(기본 1~4자)만 유효하다.
  문자셋 72개 기준 5자는 약 19억 개 조합으로, 온라인 크랙은 사실상 불가능하다.
  긴 비밀번호는 사전공격에 의존한다.
- 매우 강력한 무작위 비밀번호는 이 방식으로 뚫을 수 없다 (그것이 정상이며, 좋은 비밀번호의 조건이다).
